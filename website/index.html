Capabilities

Built for real deleted media recovery

Focused on what users actually need: photos, videos, and documents lost from local Windows disks—backed by serious forensic techniques.

01

Photos & Videos pipeline

Dedicated three-phase recovery: NTFS deleted media, Recycle Bin, then validated image/video carving with tighter JPEG, PNG, and MP4 sizing.

02

NTFS $MFT recovery

Parses deleted FILE records with update-sequence fixup, timestamps, parent paths, alternate data streams, and data-run extraction when clusters remain.

03

Native C scan engine

Optional high-throughput multi-signature scanner (Boyer–Moore–Horspool) for large volumes and images, with pure-Python fallback.

04

Forensic images

Open E01 (EnCase/EVF) evidence sets and AFF4 containers so analysis runs on the logical media, not the container file.

05

Memory & live triage

Orchestrate physical RAM capture tools, dump process memory, and collect a live triage snapshot for incident response context.

06

Case integrity

Case metadata, MD5/SHA hashing on recover, CSV/JSON reports, hex viewer—and never writes to the source media.

Workflow

Recommended recovery process

  1. Image when you can Prefer a disk image (dd / E01) over a live drive for important cases.
  2. Run as Administrator Required for raw volume access (\\.\C:) and physical disks.
  3. Select Photos & Videos Or press F5—runs NTFS, Recycle Bin, and media carve in one pass.
  4. Triage & recover Filter by type, preview, hash, then export only to a different drive.

Responsible use

Important notice

Zolvagraph is intended for legitimate data recovery, research, and training on systems you own or are authorized to examine. It is not a NIST CFTT–certified or court-validated replacement for commercial laboratory platforms used in formal investigations.

Always prefer working on forensic images, never write to source media, preserve hashes and case notes, and follow your organization’s and jurisdiction’s legal requirements.
